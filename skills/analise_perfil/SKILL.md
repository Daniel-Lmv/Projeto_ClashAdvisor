# Análise de perfil

Ative quando a pergunta incluir uma tag de jogador.

1. Consulte o MCP próprio para obter dados da API oficial.
2. Não confunda nível do Centro de Vila com nível máximo disponível no jogo.
3. Não alegue conhecer recursos armazenados ou todas as construções do jogador.
4. Se a consulta falhar, informe o motivo e não simule um perfil.
