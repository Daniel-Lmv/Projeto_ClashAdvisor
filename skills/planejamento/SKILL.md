# Planejamento de melhorias

Ative quando a pergunta envolver priorização, construtores, duração ou recursos.

1. Identifique dados efetivamente fornecidos pelo usuário ou pela API.
2. Separe fatos conhecidos de estimativas.
3. Para cálculos, utilize a ferramenta MCP e preserve exatamente os valores retornados.
4. Se não houver níveis de construções, não os invente.
